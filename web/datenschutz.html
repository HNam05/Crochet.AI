Datenschutz und Nutzung

Crochet.AI rechnet vollständig in deinem Browser. Beim ersten Besuch lädt die Seite einen Python-Rechenkern (Pyodide) und die Mustersoftware von dieser Website; danach liegt beides im Browser-Zwischenspeicher.

Deine Beschreibungen, Maße, Farben und Muster werden nicht an einen Server geschickt. Es gibt keine Konten, keine KI-Dienste, keine Analyse- und keine Werbedienste. Entwürfe und dein Häkel-Fortschritt bleiben im Speicher dieses Browsers, bis du ihn löschst.

Die Seite liegt auf GitHub Pages. Wie bei jeder Website verarbeitet GitHub dabei technische Zugriffsdaten wie die IP-Adresse, um die Dateien auszuliefern.

Die Muster sind berechnet, aber noch nicht nachgehäkelt oder nachgestrickt. Arbeite zuerst ein Testteil und miss nach; die Seite rechnet deine Maschenprobe dann nach.
